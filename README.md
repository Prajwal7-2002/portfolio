# Portfolio

Personal portfolio site of Prajwal Pujari, AI/ML engineer: services, projects and contact.

A single static page (`index.html`, plain HTML and CSS, no build step), hosted on Vercel.

## Preview locally

```bash
python -m http.server 8080   # then open http://localhost:8080
```

## Deploy

Import this repo on vercel.com (Add New → Project). Framework preset: **Other**, no build command,
no output directory. Every push to `main` redeploys.

## Updating

Projects, services and contact links are all in `index.html`. Only use numbers that appear in each
project's own write-up.
